# The Shaurma

Static GitHub Pages website for The Shaurma, Багратионовский пр., 7, корп. 20В, Москва.

The site includes a five-item menu with prices and weights, high-resolution food photography, photos of the storefront and interior, phone ordering, a Yandex Maps route, copy-address and copy-phone actions, and photo previews.

## Publish with GitHub Pages

In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/ (root)`, then save. The site will be available at `https://kirillbaluev061-alt.github.io/the-shaurma-bagrationovsky-7-20v/`.
